# 18plus Content Radar

Редакционный контент-завод для блога 18+ тематики (отношения, dating,
интимность, сексология, психология). Система находит и ранжирует видео на
YouTube, а по видео, выбранному вручную, готовит редактируемый Content Pack
(статья, карусель, Reels-сценарии, посты VK/Дзен/Telegram, промпты для
иллюстраций). Публикаций во внешние сервисы система не делает — только
исследует, ранжирует и готовит черновики, решение всегда за редактором.

## Что уже есть

- FastAPI-приложение с локальной/Postgres базой (SQLAlchemy);
- управление поисковыми тематическими запросами (`/queries`);
- реальный поиск видео через **YouTube Data API v3** по кнопке «Искать» у
  каждого запроса — с сохранением/обновлением канала и видео (просмотры,
  лайки, комментарии, превью, дата публикации, длительность);
- **Viral Score** по каждому видео с человекочитаемым объяснением, радар
  видео отсортирован по рейтингу (`/videos`);
- **история метрик** (snapshots) и, на её основе, динамика роста;
- **автопоиск по расписанию** (APScheduler): периодический поиск по всем
  включённым темам + обновление метрик найденных видео; плюс кнопки ручного
  запуска на главной;
- **Content Factory**: по кнопке «Создать контент» у видео система берёт
  субтитры YouTube (через yt-dlp, транскрипт как источник фактов) и через ИИ
  генерирует редактируемый Content Pack — статья с SEO/FAQ, заголовки,
  Instagram-карусель, Reels-сценарии, VK/Дзен/Telegram, промпты иллюстраций
  и заметки редактору; с сохранением ссылки на источник (`/content`);
- **Настройки бренда** (`/settings`): редактируемые тон/стиль, аудитория,
  CTA, стиль иллюстраций и произвольные инструкции — подмешиваются в каждый
  запрос к ИИ, чтобы контент делался под вас;
- **фильтр Shorts и языка**: короткие ролики (по умолчанию < 3 мин) и явно
  иностранные видео не попадают в радар; кнопка «Убрать неподходящие»
  чистит уже накопленное;
- Docker-конфигурация для запуска на VPS.

## Content Factory

- Транскрипт берётся из субтитров YouTube бесплатно; если субтитров нет,
  видео помечается — Whisper-fallback можно добавить позже.
- Генерация требует `AI_API_KEY` (OpenAI-совместимый). Модель настраивается
  `AI_MODEL` (по умолчанию `gpt-4o-mini`), при желании — свой endpoint через
  `AI_BASE_URL`.
- Промпт запрещает дословный пересказ: транскрипт используется только как
  источник фактов, мнение автора отделяется от проверяемых фактов, для
  чувствительных тем добавляется рекомендация обратиться к специалисту.
  Публикация всегда ручная.

## Автопоиск

Планировщик работает внутри веб-процесса и управляется через `.env`:

- `SCHEDULER_ENABLED` — вкл/выкл автопоиск (по умолчанию `true`);
- `SEARCH_INTERVAL_HOURS` — как часто искать по всем темам (по умолчанию 12);
- `METRICS_INTERVAL_HOURS` — как часто обновлять метрики найденных видео
  (по умолчанию 6).

Каждый поиск по одной теме расходует ~100 единиц дневной квоты YouTube
(бесплатно 10 000/день). При большом числе тем увеличьте интервал поиска.

## Как получить YOUTUBE_API_KEY (бесплатно)

1. Зайти в [Google Cloud Console](https://console.cloud.google.com/).
2. Создать проект (или использовать существующий).
3. В «APIs & Services → Library» включить **YouTube Data API v3**.
4. В «APIs & Services → Credentials» создать API key.
5. Вставить ключ в `.env` как `YOUTUBE_API_KEY=...`.

Бесплатная квота — 10 000 единиц/день, одного поискового запроса хватает
примерно на 100 таких запусков в день.

## Локальный запуск

1. Скопировать `.env.example` в `.env`, заполнить `YOUTUBE_API_KEY`
   (без него поиск не запустится, остальной интерфейс работает).
2. `docker compose up --build`.
3. Открыть `http://localhost:8000`.

## Деплой на VPS

Проект зависит от PostgreSQL и разворачивается через Docker Compose (см.
`docker-compose.yml`), в отличие от других ботов на этом VPS, которые живут
под Supervisor без Docker — эти подходы не пересекаются и не должны
смешиваться. Подробности — в `CLAUDE.md`.
